## 2. 玩法（想要的玩感先于机制）

**玩感**：每一席都是「理解这桌在压什么 → 选一个真的不同的代价 → 承受身体、家人、场面或立场的损失」。随机只决定你是谁、以及这一季的席序；失败能指回某一次选择。

固定身份：主角**自己**是素食者，不是「胎内素」（不是因为母亲孕期吃素而被动不吃肉）。

| 维度 | 规则 |
|---|---|
| 性别 | 女 / 男 / 非二元。改变别人用的标签；男客在「客户应酬」守盘或离席多掉 1 场面。三种都能走到全部胜局。 |
| 性格 | 稳 / 软 / 烈。`--content` 可锁定。稳更容易说动人、离席较轻；软同席少掉立场但开局立场低；烈对外加分、对家里减分，离席立场涨得多。 |
| 家庭 | 无肉不欢 / 素食家庭。肉食家庭开局家人更低，没素菜的家里硬守或离席叠「冲突」。素食家庭家人更高，但家人理由（伦理 / 信仰 / 养生）可能和你的理由（再加口味）不同。 |
| 席 | 十六席，固定四段：家里、校园、出门、立席。每段四席，段内顺序由 seed 洗牌。当前席的热度、有没有素菜，行动前就写在状态里。 |

指标（0–8，备菜 0–3）：

- **身体**：空桌硬守、离席、没说动、咬肉都会掉。到 0 → 厌食。
- **家人**：家里这一席的关系。到 0 → 断席。
- **场面**：校园与出门。到 0 → 标签。
- **立场**：你还说不说得清自己为什么不吃肉。到 0 → 随席。
- **备菜**：自己灶上 `stock`，空桌用 `bring` 摆上去。
- **冲突**（仅肉食家庭）：没素菜且热度 ≥ 2 的家里，硬守 / 离席 / 没说动 +1。冲突 ≥ 3 且身体 ≤ 2、家人 ≤ 2 → 冲突。家人先到 0 仍算断席。

动作（只列出这一席合法的）：

| id | 差别 |
|---|---|
| `hold` | 守自己的盘子。有素就回身体；热度 ≥ 2 才涨立场并掉关系，安静的素菜桌不涨立场。没素扣身体，家里还可能叠冲突。 |
| `share` | 同席只夹素、不摊牌。热度 ≤ 2 涨关系；热度 3 不涨关系，并扣身体和立场。软的人在低热度不掉立场。 |
| `name` | 1d6 + 性格/难度修正。日志写点数、修正、需要的线。说动涨关系与立场；没说动掉关系，吃饭的席还扣身体。成功率是 0 的席不列入动作。 |
| `bring` | 消耗 1 备菜，把菜摆上没有素的桌子。身体、立场、关系都涨，不叠冲突。 |
| `bite` | 为场面咬一口肉。关系 +2，身体 −2，立场 −2。这一口不提供体力。 |
| `leave` | 离席。稳伤关系较轻，烈立场涨得多。吃饭的席还扣身体。 |
| `stock` | 只在自己的灶。备菜 +2（上限 3），身体 +1，立场 +1。备菜已满则不再出现。 |
| `differ` | 素食家庭且理由不同、还没说开。家人 −1，立场 +1，打开「分席」。 |
| `settle:host` / `truce` / `script` / `split` | 只在立席、且门槛已够时出现。 |

胜（立席主动收束，活过十六席本身不算赢）：

- **自席** `host`：立场 ≥ 6，身体 ≥ 3，备菜 ≥ 1
- **同桌** `truce`：家人 ≥ 6，身体 ≥ 3，立场 ≥ 2
- **外席** `script`：场面 ≥ 7，身体 ≥ 3，立场 ≥ 4
- **分席** `split`：素食家庭、理由不同且已说开，家人 ≥ 4，立场 ≥ 5，身体 ≥ 3

负：厌食、断席、标签、随席、冲突、没收束（第十六席后仍不收束）。

反支配：只守空桌会厌食或断席或冲突；只同席会随席；只咬肉会随席且不回体力；备菜要花掉灶上那一席，囤满后 `stock` 消失。肉食家庭与素食家庭的最优收束不同。

## 3. 假设与风险

- 假设：gamekit 契约不变，不改其他游戏的规则。
- 风险：动作列表过长 → 按席种裁剪，0% 的 `name` 不列出。
- 风险：胜负不可归因 → 判定写入 events；门槛写在状态「收束」段。
- 版本：现行包是 2.2.0，部分 `GAME_VERSION` 仍停在 2.1.0。本次全部对齐到 2.3.0，不改那些游戏的玩法。

## 5. 平衡

单按钮策略站不住：只同席走到「随席」，只守盘在肉食家庭走到断席或冲突。会混着守素菜桌、在低热度同席、热度 3 改用备菜的打法，在六种开局 × 40 个 seed 上大约九成能收束，肉食家庭仍会留下厌食、随席和没收束。外席要场面 ≥ 7，所以只靠吵桌上的沉默攒不到。
