- Existing untracked `KIMI_V260_TASK.md` is user-provided input and will be left
  untouched and out of the commit.

  do not require a migration.

  change the legal action set or deterministic action resolution.
- Clamping integrity must preserve the existing zero-integrity loss condition.
- Broad version edits can miss content-module re-exports or skill metadata;
  validation must search for stale 2.5.0 runtime/package declarations.
