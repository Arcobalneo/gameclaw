# 虾素 (Shrimp Greens)

十六席的素食者人生。你不是去评价素食，你是去过这个人的饭桌：家里、校园、出门，然后决定这张桌子最后怎么摆。

```bash
shrimp-greens new --seed 7
shrimp-greens act hold
shrimp-greens act share
shrimp-greens recap
```

当前版本 `3.1.0`，运行在 GameClaw 的 TypeScript `gamekit` v2 运行时上。

## 为什么它是 agent-first 的

- **一次调用 = 一席**。`act` 返回本席日志、完整状态与下一批合法动作。
- **开局随机，但开局之后不再靠抽签活着**。性别、性格、家庭、理由和十六席的顺序由 seed 决定，并写进状态。当前席有没有素菜、热度多高，选动作之前就看得见。
- **每个动作的代价写在 `cost` 里**。`name` 的成功率写在 `detail` 里（约 x/6）。掷骰结果写进 `events`。
- **失败能指回去**。厌食、断席、标签、随席、冲突、没收束，各自对应一条看得见的归零条件。
- **活到最后不算赢**。立席要自己收束。`memoryPrompt` 要求记下这一局的家庭和打法，并写明换一户人家要重新验证。

## 你是谁

主角**自己**吃素。这不是「胎内素」：不是母亲孕期吃素，所以你天生不吃。

| 维度 | 取值 | 作用 |
|---|---|---|
| 性别 | 女 / 男 / 非二元 | 别人用来叫你的词不同。男客在「客户应酬」守空盘或离席，场面多掉 1。三种都能走到全部胜局。 |
| 性格 | 稳 / 软 / 烈 | 稳：解释 +1，离席关系只 -1。软：开局立场 2，同席很少掉立场。烈：开局立场 5、备菜 1；对家里人解释 -1，对外面 +1，离席立场 +2。 |
| 家庭 | 无肉不欢 / 素食家庭 | 肉食家庭家人 -1，并启用冲突条。素食家庭家人 +2，但家人的理由可能和你不同。 |
| 你的理由 | 伦理 / 信仰 / 养生 / 口味 | 只影响和家里的理由差不差，不提供隐藏加成。 |

`--content` 用冒号拼：`sharp:meat`、`soft:veg:gap`、`male:steady:meat`。`gap` 保证素食家庭的理由和你不一样。不写的维度仍由 seed 抽。

`--difficulty easy` 开局身体和家人 +1，解释 +1。`hard` 相反。

## 十六席

家里 4、校园 4、出门 4、立席 4。每段内部的顺序由 seed 洗牌，四席都会出现。

状态路径：

- `state.body` 身体，0–8，到 0 为厌食
- `state.home` 家人，到 0 为断席
- `state.room` 场面，到 0 为标签
- `state.line` 立场，到 0 为随席
- `state.prep` 备菜，0–3
- `state.clash` 冲突，只在肉食家庭叠
- `state.family` / `state.gender` / `state.personality` / `state.reason` / `state.houseCreed`
- `state.creedGap` / `state.namedDifference`
- `state.scenes` 十六席的具体菜单（含 `vegOnTable` 与 `heat`）
- `state.rng` sfc32 四字状态

## 动作

| id | 什么时候有 | 代价的方向 |
|---|---|---|
| `hold` | 吃饭、灶、收束席 | 有素就回身体。热度 ≤ 1 的素菜桌不涨立场；热度 ≥ 2 才涨立场并掉关系。没素扣身体。热度 ≥ 2 的肉食家里还会 +1 冲突 |
| `share` | 吃饭、被人贴标签 | 热度 ≤ 2 的空桌涨关系。热度 3 不涨关系，还扣身体和立场。软的人在低热度不掉立场 |
| `name` | 吃饭或谈话，且成功率 > 0 | 1d6 + 修正。说动：关系 +2、立场 +1；没说动：关系 -1，吃饭的席再扣身体 |
| `bring` | 没素菜且备菜 ≥ 1 | 备菜 -1，身体 +1，立场 +1，关系 +1，不叠冲突 |
| `bite` | 桌上有肉 | 关系 +2，身体 -2，立场 -2。这一口不提供体力 |
| `leave` | 吃饭或谈话 | 离席。稳的人关系 -1，烈的人立场 +2。吃饭的席扣身体，家里还可能叠冲突 |
| `stock` | 自己的灶，且备菜未满 | 备菜 +2（上限 3），身体 +1，立场 +1 |
| `differ` | 素食家庭、理由不同、还没说开，且这席是家人或已到立席 | 家人 -1，立场 +1，打开分席 |
| `settle:host` | 立席，立场 ≥ 6，身体 ≥ 3，备菜 ≥ 1 | 自席，消耗 1 备菜 |
| `settle:truce` | 立席，家人 ≥ 6，身体 ≥ 3，立场 ≥ 2 | 同桌 |
| `settle:script` | 立席，场面 ≥ 7，身体 ≥ 3，立场 ≥ 4 | 外席 |
| `settle:split` | 立席，素食家庭且分歧已说开，家人 ≥ 4，立场 ≥ 5，身体 ≥ 3 | 分席 |

门槛的现值和「可走 / 未到」写在状态的「收束」段。不够的收束不会出现在动作列表里；已经出现收束时，`next` 会优先推荐它，而不是继续 `hold`。

## 结局

胜：`自席`、`同桌`、`外席`、`分席`。

负：

- `厌食`：身体先到 0。空肚子硬守，或咬了不该咬的。
- `断席`：家人先到 0。
- `标签`：场面先到 0。
- `随席`：立场先到 0。人还坐得下去，身份已经说不清。
- `冲突`：肉食家庭，冲突 ≥ 3，且身体 ≤ 2、家人 ≤ 2。家人若先到 0，仍然算断席。
- `没收束`：十六席走完却没有收束。只是活着，盘子没放稳。

`abort` 是中止，不算胜也不算负。
