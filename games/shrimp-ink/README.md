# 虾写 (Shrimp Ink)

十八幕命笔游历。传说有一支笔，写下什么就成什么。你要在十八幕里决定：信不信它，找不找它，找到以后敢不敢用它。

```bash
shrimp-ink new --seed 7
shrimp-ink act travel:stele
shrimp-ink act investigate
shrimp-ink act dig
shrimp-ink recap
```

当前版本 `3.0.0`，运行在 GameClaw 的 TypeScript `gamekit` v2 运行时上。

## 为什么它是 agent-first 的

- **一次调用 = 一个动作**。`act` 返回本幕日志、完整状态与下一批合法动作；agent 不需要在 `status` / `actions` 之间反复轮询。
- **稳定文本锚点**。`GAME / STATE / STAT / ACTIONS / NEXT` 的结构可以直接正则解析。
- **`--json` 输出**。每幕一个 JSON 对象，包含 `status`、`actions`、`events`、`observer`、`report` 与 `next`。
- **确定性**。同一 seed + 同一动作序列 = 完全相同的结局；save 里保存 sfc32 的 `rng` 状态，可回放、可做回归测试。
- **动作带代价**。每个 `ActionView` 都写明银、粮、命或墨债的消耗，不靠猜。

## 核心循环

一个 run 是 **18 幕**，每幕 **1 个动作**。六处地点：

| 地点 | 性质 | 作用 |
|---|---|---|
| 归墟镇 `town` | 市集 | 接零工、买粮；起点与退路 |
| 断碑坡 `stele` | 野址 | 问牧人、拾野果；可能埋笔 |
| 雾渡口 `ferry` | 野址 | 买干粮、听船夫；最便宜的补给 |
| 墨池 `pool` | 野址 | 听墨声涨信但掉命；线性索更容易成真 |
| 荒庙 `temple` | 野址 | 验线索、验笔；唯一能求证的地方 |
| 皇驿 `post` | 官道 | 递名帖、打点；售笔与封笔只能在这里 |

三条资源：**银**（打听、验线索、验笔）、**粮**（每幕 -1，赶路再 -1）、**命**（挖土、墨噬、夺笔者）。断粮掉命，命归零就是 `墨尽`。

两条认知线：

- **信 `belief`**：越高越容易打听到真线索，也越容易把假话当成真的。信 ≥ 60 时可以直接挖出笔。
- **证 `proof`**：荒庙验线索、验墨都能涨证。证 ≥ 2/3/4（随售笔次数抬升）时可以靠证据挖出笔，证 ≥ 3 时挖到就能直接开笔。

## 动作表

| 动作 | 代价 | 作用 |
|---|---|---|
| `travel:<site>` | 1 粮（另计每幕 1 粮） | 走到相邻地点 |
| `investigate` | 2 银 | 在野址打听一条线索：可能真，可能假；银不足 2 时不列出 |
| `verify` | 2 银 | 只能在荒庙：验真涨证 +1、信 +6；验假掉信 -8；银不足 2 时不列出 |
| `dig` | 1 命 | 在野址挖土。只有站在真笔址且信/证达标才会出土；只剩 1 命时不列出 |
| `probe` | 3 银 | 只能在荒庙：验笔三次，验满才能落笔；银不足 3 时不列出 |
| `write:heal` | 墨债 +1 | 命 +2 |
| `write:gold` | 墨债 +1 | 银 +10 |
| `write:erase` | 墨债 +2 | 名望 +3、银 +6 |
| `settle:sell` | — | 只能在皇驿：售笔，银 +25、名望 +4，永久失去 |
| `settle:seal` | — | 只能在皇驿：封笔，名望 +6，无债另有加分 |
| `talk:<id>` | 视对象 | 十二段一次性对话：补给、涨信、涨证、换名望 |

## 真正的张力

**信与证是两条不同的赢法，不是同一条路上的两个数值。** 信者开局信 72，查到真线索的概率更高，但假线索到手里也像真的；疑者开局证 1、银 15，走得慢，却能把每条线索验成可用的证据。录者居中，靠书稿计分。

**挖错一次就是一条命。** 挖土失败不会告诉你「这里不是」，只给同一段模糊文案。你得靠线索、验线索和同行者的判断，而不是靠试错把四个野址挖一遍。

**用笔的收益是真的，墨债也是真的。** 债 ≥ 3 起每次落笔都可能反噬（-2 命），≥ 5 每幕再掉 1 命，≥ 6 直接 `墨噬`。十八幕里最多安全用两次。

**售笔是最稳的变现，也是最低的结局分。** 而且它会写进这一局的复盘：下一个角色要拿笔，门槛更高。这是原作里「系统会记录」的转译。

**没找到笔也能收尾。** 信得深是 `寻笔`，不信而一路劝人是 `劝世`，书稿照样计分。这是对原作第四条支线的保留。

## 九种收尾

`执笔` / `证笔` / `售笔` / `封笔` / `寻笔` / `劝世` / `墨尽` / `墨噬` / `收壳`。

`recap --format markdown` 输出标题、结局、归因、关键指标、最近 10 条时间线、单局教训，以及一段给 agent 写进自己记忆的 `memoryPrompt`。
